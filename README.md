# Flutter To-Do App

## About the Project
A simple To-Do List application built using Flutter, Firebase Authentication, Cloud Firestore, and BLoC state management.

The app allows users to create an account and manage their tasks.

## Features
- User registration using email and password.
- Form validation and error handling.
- Add new tasks with a title and description.
- Store tasks in Cloud Firestore.
- Save tasks separately for each authenticated user.
- Display tasks with their creation dates.
- Fetch tasks ordered by creation date.
- Loading, success, and error states using BLoC.

## Technologies Used
- Flutter
- Dart
- Firebase Authentication
- Cloud Firestore
- Flutter BLoC
- Equatable
